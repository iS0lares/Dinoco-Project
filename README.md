# Dinoco

Diário automotivo de Moisés Solares. A animação da abertura usa a arte derivada da foto do carro.

`npm ci` instala as dependências. `npm run dev -- --port 3001` abre o diário em http://localhost:3001.

Cadastre as modificações em `src/content/build.ts`. Informe o título, a descrição e, se houver, a data e o caminho da foto. Coloque as fotos em `public/`.
